# Router

Which folders exist and what mode each is in. A fact, not a decision. Rebuilt by script and
compared, never hand-curated into disagreement with the tree.

## Wings

| Wing | Charter | Granted |
|---|---|---|
| `<wing>` | `<wing>/CHARTER.md` | `<YYYY-MM-DD>` |

## Folders

| Wing | Folder | Mode | Holds | Promoted |
|---|---|---|---|---|
| `<wing>` | `<wing>/01-name/` | built | `CONTEXT.md` | `<YYYY-MM-DD>` |
| `<wing>` | `<wing>/02-other/` | under construction | `CONTRACT.md` | |

## Rules

- A folder holding `CONTRACT.md` and no promoted `CONTEXT.md` is under construction.
- A folder holding a promoted `CONTEXT.md` is built.
- Promotion is the operator accepting an emitted contract. Not the agent finishing, and not the
  audits passing.
- A wing's territory, doors, capability and ceiling live in its charter, never here. This file
  says what exists and what mode it is in. Facts in one place, grants in the other.
- Every folder is named for the work done in it, never for the product it emits. A name that
  describes an artifact is a finding.
- This file holds no order, no dependencies, and no flow. If it grows past the tables, something
  was put here that belongs on a card or in a contract.
