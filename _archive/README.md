# Archive

Files that were superseded, kept because deleting them loses the reason they existed.

Inherited from ICM: superseded material is proposed for `_archive/`, never silently deleted.
Every file here carries a dated note at the top saying what replaced it and why. Nothing in
this folder is live, nothing routes to it, and nothing should be read as current method.

Git history holds the same content. This folder holds the *reasoning*, which git history
compresses away: a diff shows that a file was removed, not why the argument in it stopped
being true.
